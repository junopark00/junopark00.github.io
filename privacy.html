개인정보처리방침

시행일: 2026년 8월 26일

점메추(https://junopark00.github.io, 이하 "서비스")는 이용자의 개인정보를 소중히 여기며, 관련 법령을 준수합니다. 본 방침은 서비스가 어떤 정보를 어떻게 처리하는지 설명합니다.

1. 수집하는 정보

  • 로그인 식별자 — 카카오 또는 Google 계정으로 로그인하면 해당 플랫폼이 발급하는 회원 식별 번호만 수신합니다. 이름, 이메일, 프로필 사진 등 다른 개인정보는 수집하지 않습니다.
  • 별점 데이터 — 로그인한 이용자가 가게에 남긴 별점(1~5점)을 회원 식별 번호와 함께 저장합니다.
  • 위치 정보 — 주변 음식점 검색을 위해 이용자가 선택하거나 허용한 좌표가 검색 요청에 사용됩니다. 좌표는 검색 처리에만 이용되며 서버에 저장하지 않습니다.
  • 브라우저 저장소(localStorage) — 검색 조건, 마지막 위치, 로그인 토큰, 별점 캐시 등이 이용자 기기의 브라우저에만 저장됩니다.

2. 정보의 이용 목적

  • 주변 음식점 검색 및 추천 기능 제공
  • 가게 별점 등록·조회 (이용자당 가게별 1개 별점 유지)
  • 서비스 이용 편의 유지 (검색 조건 기억 등)

3. 제3자 서비스

서비스는 다음 외부 서비스를 이용하며, 각 서비스의 개인정보 처리에 대해서는 해당 사업자의 방침이 적용됩니다.

  • 카카오 — 지도 표시, 장소 검색, 카카오 로그인 (카카오 개인정보처리방침)
  • Google — Google 로그인, Google 애드센스 광고 (Google 개인정보처리방침). 애드센스는 광고 제공을 위해 쿠키를 사용할 수 있습니다.
  • SK open API (TMAP) — 도보 소요 시간 계산을 위한 좌표 전달
  • Cloudflare — API 중계 및 별점 데이터 저장

4. 보유 및 파기

  • 별점 데이터는 서비스 운영 기간 동안 보관됩니다.
  • 브라우저 저장소의 데이터는 이용자가 브라우저에서 직접 삭제할 수 있습니다.
